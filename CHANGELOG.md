# Changelog

## 0.1.0-alpha.1

- Draft HTML-fragment language with explicit roles, sections, text, and bounded variables.

- Root-to-target rules loading with monotonic policy and aggregate context checks.
- CLI JSON interface, generated JSON Schemas and TypeDoc API reference.
- Homepage, guide, standalone specification, runnable examples, and project contribution infrastructure.
